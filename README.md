🎯 О проекте
Hair&Care Business Monitor — это веб-приложение (CRM) для автоматизации работы салонов красоты и барбершопов. Система позволяет:

Вести базу клиентов и услуг

Управлять расписанием записей

Отслеживать выручку и ключевые метрики бизнеса

Подключать Telegram/MAX-бота для самостоятельной записи клиентов

Разграничивать права владельца и сотрудников

Проект находится в стадии активной разработки (MVP).

🚀 Установка и запуск
1. Клонирование репозитория
bash
git clone https://github.com/your-username/hair-care-monitor.git
cd hair-care-monitor
2. Создание виртуального окружения
Windows:

bash
python -m venv venv
venv\Scripts\activate
Linux / macOS:

bash
python3 -m venv venv
source venv/bin/activate
3. Установка зависимостей
bash
pip install -r requirements.txt
4. Настройка переменных окружения
Создайте файл .env в корне проекта:

env
SECRET_KEY=your-secret-key-here
DATABASE_URL=sqlite:///instance/database.db
BASE_URL=http://localhost:5000
FLASK_ENV=development
⚠️ Для продакшена обязательно смените SECRET_KEY на случайную строку.

5. Запуск приложения
bash
python run.py
Приложение будет доступно по адресу: http://localhost:5000

При первом запуске автоматически создастся база данных.

6. Первый вход
Откройте http://localhost:5000/register

Зарегистрируйтесь как владелец бизнеса

Создайте бизнес

Добавьте услуги и начните работу

🤖 Настройка бота
Telegram
Найдите в Telegram @BotFather

Отправьте команду /newbot

Придумайте имя и username бота

Скопируйте полученный токен

В CRM перейдите в 🤖 Настройки бота и вставьте токен

Скопируйте Webhook URL и укажите его в настройках бота

MAX
Зарегистрируйтесь в MAX Business

Создайте нового бота в личном кабинете

Скопируйте токен

Аналогично укажите в CRM

Для работы webhook в продакшене требуется публичный HTTPS-домен.

🔌 API
API используется ботом для взаимодействия с CRM. Все запросы авторизуются по bot_token.

Эндпоинты для бота
Метод	Эндпоинт	Описание
GET	/api/bot/services?token=...	Список услуг бизнеса
POST	/api/bot/check_slot	Проверка свободного слота
GET	/api/bot/free_slots?token=...&date=...	Свободные слоты на дату
POST	/api/bot/create_appointment	Создание записи
GET	/api/bot/my_appointments?token=...&chat_id=...	Записи клиента
POST	/api/bot/cancel_appointment	Отмена записи
Эндпоинты для веб-интерфейса
Метод	Эндпоинт	Описание
POST	/api/bot/save_token	Сохранение токена бота
GET	/api/bot/get_token	Получение токена
GET	/api/bot/webhook_url	Webhook URL
GET	/api/business/info	Информация о бизнесе
